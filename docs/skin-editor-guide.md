# 字幕皮肤编辑器使用说明

字幕皮肤编辑器用于给字幕窗口叠加 PNG/WebP 贴图，并通过关键帧和事件让贴图产生动作。它既可以制作静态字幕装饰，也可以制作类似桌宠的动态皮肤。

如果你第一次使用，建议先完成下面的“5 分钟快速上手”，确认静态贴图能够正常显示，再继续制作动作和事件。

## 1. 打开编辑器

可以从以下任一入口打开：

- 系统托盘右键 → **桌宠皮肤** → **打开皮肤编辑器…**。
- 主窗口设置 → **皮肤** → **🎨 打开皮肤编辑器**。

在设置的 **皮肤** 页面还可以调整：

- **启用贴图皮肤**：是否在字幕窗口中显示当前皮肤。
- **动画帧率**：皮肤动画的运行帧率。
- **循环播放**：动画结束后的默认播放行为。
- **网格吸附**：拖动图层时按网格对齐。
- **网格尺寸**：每格的像素大小。
- **显示辅助线**：在编辑画布中显示对齐参考线。

## 2. 5 分钟快速上手

### 第一步：新建皮肤

1. 点击顶部工具栏的 **新建**。
2. 输入皮肤名称，例如“粉色猫咪”。
3. 编辑器顶部的 **正在编辑：** 下拉框、窗口标题和底部状态栏都会显示当前皮肤。

窗口标题中皮肤名称后的 `*` 表示当前内容尚未保存。

### 第二步：添加图片

1. 打开左侧 **图层** 标签页。
2. 点击 **+图片**。
3. 选择一张透明背景的 PNG 或 WebP 图片。
4. 图片会被复制到皮肤自己的素材目录，不需要一直保留原始文件位置。

如果素材本身是一组动画帧，请使用 **+序列**，并一次选择按播放顺序排列的 PNG/WebP 图片。

### 第三步：选中并摆放图片

可通过两种方式选中图层：

- 点击左侧图层列表中的图片名称。
- 直接点击中央预览画布中的图片实体。

选中后会出现选框和操作手柄：

- 拖动图片：移动位置。
- 拖动缩放手柄：等比例缩放。
- 拖动旋转手柄：旋转图片，默认按 5° 吸附。
- 按方向键：按网格尺寸移动；未启用网格时每次移动 1 像素。
- 拖动或旋转时按住 `Alt`：临时关闭网格或角度吸附。

也可以在右侧 **变换** 区域直接输入精确数值。

### 第四步：保存并应用

1. 点击顶部工具栏的 **保存**，或按 `Ctrl+S`。
2. 保存成功后，皮肤会立即成为当前字幕皮肤。
3. 回到字幕窗口检查实际显示效果。

如只想临时查看未保存的效果，可点击 **应用预览**。该操作不会代替保存；关闭编辑器后，临时预览会恢复为打开编辑器前的皮肤。

## 3. 界面区域说明

编辑器由五个主要区域组成：

| 区域 | 用途 |
| --- | --- |
| 顶部工具栏 | 新建、打开、保存、导入导出、切换皮肤、撤销重做、播放动画和应用预览 |
| 左侧标签页 | 管理 **图层**、**动作** 和 **事件** |
| 中央预览画布 | 预览字幕窗口和皮肤，直接选择、移动、缩放、旋转贴图 |
| 右侧属性面板 | 编辑当前图层的结构、变换参数和关键帧 |
| 底部时间轴 | 查看、选择、移动、复制和缩放关键帧 |

中央画布会镜像当前字幕窗口的尺寸。外部调整字幕窗口大小后，编辑器会同步更新映射，字幕和贴图不会因为窗口缩放而被简单拉长或压扁。

## 4. 当前皮肤、切换与保存

### 确认当前编辑的是哪个皮肤

- 顶部 **正在编辑：** 下拉框显示当前皮肤。
- 窗口标题显示“字幕皮肤编辑器 — 皮肤名”。
- 底部状态栏显示皮肤名称、保存状态和所在目录。
- 标题中的 `*` 和状态栏中的“未保存”表示存在未保存修改。

### 切换皮肤

从顶部 **正在编辑：** 下拉框选择其他皮肤即可切换。若当前皮肤有未保存修改，编辑器会询问：

- **保存**：保存当前修改后切换。
- **放弃**：不保存当前修改，直接切换。
- **取消**：留在当前皮肤继续编辑。

也可以使用顶部 **打开**，直接选择某个皮肤目录中的 `skin.json`。

### 新建、保存与撤销

- **新建**：建立一个空白皮肤，设计尺寸取自当前字幕窗口。
- **保存**：保存 `skin.json` 和缩略图，并立即应用到字幕窗口。
- **撤销 / 重做**：撤回或恢复编辑操作，快捷键为 `Ctrl+Z` / `Ctrl+Y`。

建议完成一个阶段就保存一次，尤其是在制作大量关键帧之前。

## 5. 图层与贴图

### 静态图片与序列帧

- **+图片**：添加一张 PNG/WebP，适合身体、边框、角标等静态部件。
- **+序列**：添加多张 PNG/WebP 作为逐帧动画，选择文件时应按期望的播放顺序排列。
- **序列帧率**：控制序列每秒播放多少张图片。
- **序列帧循环**：播放到最后一帧后是否从第一帧重新开始。

优先使用带透明通道的 PNG 或 WebP。序列帧最好保持相同画布尺寸和对齐位置，避免播放时抖动。

### 图层列表

左侧列表从上到下表示视觉上的前后顺序。可以：

- 点击名称选择图层。
- 勾选或取消勾选控制 **显示**。
- 双击名称进行重命名。
- 拖动列表项调整顺序。
- 点击 **复制** 创建副本。
- 点击 **删除** 删除选中图层。

列表名称前的 `[上]` 或 `[下]` 表示该图层位于字幕文字的上方或下方。

### 图层属性

选中图层后，右侧 **图层** 区域可设置：

- **名称**：图层名称。
- **显示**：是否渲染该图层。
- **锁定**：锁定后不能在画布上拖动、缩放或旋转，适合防止误操作。
- **层级**：选择 **字幕上方** 或 **字幕下方**。
- **水平锚定**：`left`、`center`、`right`。
- **垂直锚定**：`top`、`center`、`bottom`。

“锚定”决定字幕窗口尺寸变化时图层跟随哪一侧。例如右上角装饰通常使用 `right + top`，这样窗口变宽时仍贴近右上角。

### 变换属性

右侧 **变换** 区域包含所有可以制作关键帧动画的属性：

| 属性 | 含义 |
| --- | --- |
| `x` | 水平位置，正值向右 |
| `y` | 垂直位置，正值向下 |
| `scale_x` | 水平缩放，`1` 为原始大小 |
| `scale_y` | 垂直缩放，`1` 为原始大小 |
| `rotation` | 旋转角度 |
| `opacity` | 不透明度，`0` 完全透明，`1` 完全不透明 |

在 **基础状态（无动作）** 下修改这些数值，会改变图层平时的默认姿态；在某个动作下修改，则可生成该动作的关键帧。

### 让图片超出字幕窗口

`x` 和 `y` 可以把图片放到原字幕内容区域之外，例如挂在右上角。实际字幕窗口会根据皮肤的可见范围扩展，扩展区域中没有贴图的部分保持透明并支持点击穿透。

字幕窗口自己的工具栏和按钮始终位于皮肤图层上方；即使贴图覆盖到工具栏位置，工具栏仍应能够正常显示和点击。

## 6. 动作与关键帧

### 什么是动作

动作是一个独立的动画片段，例如“摇尾巴”“眨眼”“跳一下”。每个动作都有自己的时间轴和播放设置，不会直接改坏其他动作。

左侧打开 **动作** 标签页后：

- **基础状态（无动作）**：编辑贴图平时的默认姿态，不显示动作时间轴内容。
- **新建**：创建独立动作片段。
- **复制**：复制当前动作及其关键帧。
- **删除**：删除当前动作。
- 双击动作名称：重命名。

### 动作设置

- **时长**：动作持续多少秒。
- **优先级**：多个动作竞争时，数值更高的动作优先。
- **循环**：是否重复播放。
- **循环次数**：循环播放的次数。
- **允许高优先级动作打断**：启用后，更高优先级动作可以中断当前动作。
- **动作冷却**：该动作播放后，多久内不再次播放。

### 创建关键帧

关键帧用于记录“某个时间点，某个属性应该是多少”。例如尾巴在 0 秒为 -10°，在 0.3 秒为 20°，软件会自动计算中间过程。

推荐操作流程：

1. 在 **动作** 中新建或选择一个动作。
2. 在 **图层** 中选择要运动的图片。
3. 在底部时间轴点击目标时间，移动红色播放头。
4. 在右侧 **当前属性** 选择要修改的属性。
5. 在 **插值** 中选择运动方式。
6. 修改变换数值，或直接在画布上拖动、缩放、旋转。
7. 启用 **动作编辑时自动打点** 时，修改会自动在当前时间添加或更新关键帧。
8. 未启用自动打点时，点击 **添加/更新** 手动记录关键帧。

点击 **删除** 会删除当前图层、当前属性、当前时间位置的关键帧。

### 插值方式

“插值”决定两个关键帧之间怎样变化：

- `linear`：匀速变化，最容易理解。
- `ease_in`：慢慢启动，后段加快。
- `ease_out`：前段较快，慢慢停下。
- `ease_in_out`：启动和停止都较柔和。
- `bezier`：贝塞尔曲线缓动，适合更自然的运动。
- `step` / `hold`：保持前一个值，到下一个关键帧时瞬间切换，适合闪烁或换帧效果。

第一次制作建议使用 `linear` 或 `ease_in_out`。

### 使用时间轴

时间轴每一行对应一个可动画属性，菱形代表关键帧，红线代表当前时间。

- 点击空白时间位置：移动播放头。
- 点击关键帧：选择关键帧。
- `Ctrl+点击`：增加或取消单个关键帧选择。
- `Shift+拖动空白区域`：框选多个关键帧。
- 拖动选中的关键帧：整体移动时间；默认会吸附到帧和附近关键帧。
- 拖动时按住 `Alt`：临时取消吸附到其他关键帧。
- `Ctrl+C` / `Ctrl+V`：复制关键帧，并从当前播放头位置粘贴。
- `Delete` 或 `Backspace`：删除选中的关键帧。
- **关键帧×0.5**：将选中关键帧之间的时间间隔压缩为一半，动作更快。
- **关键帧×2**：将选中关键帧之间的时间间隔扩大一倍，动作更慢。

顶部 **播放/暂停** 或空格键用于预览当前动作；**停止** 会停止播放并回到 0 秒。

## 7. 事件触发

事件用于决定“什么时候播放哪个动作”。请先创建动作，再创建事件。

### 创建事件

1. 打开左侧 **事件** 标签页。
2. 点击 **新建**。
3. 选择 **事件类型** 和 **触发动作**。
4. 勾选 **启用**。
5. 根据事件类型填写对应条件。
6. 点击 **测试**，确认动作能够被触发。

### 事件类型

| 事件类型 | 触发时机 | 主要参数 |
| --- | --- | --- |
| `timer` | 按固定周期触发 | 间隔、首次延迟 |
| `random` | 在随机时间间隔后触发 | 随机最小、随机最大 |
| `on_start` | 语音识别开始时 | 无额外条件 |
| `on_stop` | 语音识别停止时 | 无额外条件 |
| `on_text` | 收到任意字幕文本时 | 无额外条件 |
| `on_partial` | 收到识别中的临时字幕时 | 无额外条件 |
| `on_final` | 收到最终确认字幕时 | 无额外条件 |
| `on_idle` | 一段时间没有新字幕时 | 空闲时间 |
| `keyword` | 字幕包含指定文字时 | 关键词、区分大小写 |
| `regex` | 字幕匹配正则表达式时 | 正则表达式、区分大小写 |
| `volume_above` | 音量持续高于阈值时 | 音量阈值、持续时间 |
| `volume_below` | 音量持续低于阈值时 | 音量阈值、持续时间 |
| `window_show` | 字幕窗口显示时 | 无额外条件 |
| `window_hide` | 字幕窗口隐藏时 | 无额外条件 |
| `on_click` | 点击贴图实体时 | 点击图层、鼠标按键 |

`on_click` 的鼠标按键使用 `left`、`right`、`middle`，分别代表左键、右键和中键。透明区域保持点击穿透；只有实际可见的贴图像素会响应贴图点击事件。

### 通用触发限制

- **触发冷却**：本事件两次成功触发之间的最短间隔。
- **动作播放中允许重新触发**：同一动作正在播放时，是否允许从头再次触发。
- **触发概率**：`1` 表示每次都触发，`0.5` 表示约一半概率触发。
- **最多次数（0无限）**：本次皮肤运行期间最多触发多少次。
- **优先级覆盖**：临时覆盖动作本身的优先级；选择“使用动作值”则沿用动作设置。

如果事件没有反应，优先检查：事件是否启用、是否选择了触发动作、动作是否处于冷却、概率是否过低，以及当前是否有更高优先级动作占用同一图层。

## 8. 示例：制作一只会摇尾巴的猫

准备两张透明 PNG：猫身体和单独的尾巴。尾巴图片的透明画布应预留旋转空间，并尽量让尾巴根部靠近图片中心，方便旋转。

1. 新建皮肤，点击 **+图片** 添加猫身体。
2. 再次点击 **+图片** 添加尾巴。
3. 在图层列表中调整顺序，让身体遮住尾巴根部。
4. 分别选中两个图层，摆放到正确位置；完成后可锁定身体图层。
5. 打开 **动作**，新建“摇尾巴”，时长可先设为 `0.8 s`。
6. 选择尾巴图层，在 0 秒给 `rotation` 添加一个关键帧，例如 `-12`。
7. 在 0.4 秒添加第二个关键帧，例如 `18`。
8. 在 0.8 秒添加第三个关键帧，例如 `-12`。
9. 插值选择 `ease_in_out`，点击 **播放/暂停** 检查效果。
10. 打开 **事件**，新建一个 `random` 事件，触发动作选择“摇尾巴”。
11. 设置随机最小和随机最大，例如 8 秒与 20 秒，勾选 **启用**。
12. 点击 **测试**，确认后点击 **保存**。

如果尾巴旋转中心不理想，可以在绘图软件中调整尾巴素材的透明画布和内容位置，再重新添加素材。

## 9. 导入与导出

- **导出包**：将当前皮肤定义和全部素材打包为 ZIP，适合备份或分享。
- **导入包**：从 ZIP 导入皮肤。若存在同名皮肤，可以选择覆盖，或自动另存为新皮肤。

分享皮肤时优先使用 **导出包**，不要只复制 `skin.json`，否则可能遗漏 `assets` 中的图片。

## 10. 常见问题

### 添加图片后选不到，无法移动

- 直接点击左侧图层列表中的图片名称，或点击画布中的图片实体。
- 查看右侧是否显示“图层：名称”；若仍显示“未选择图层”，说明尚未选中。
- 检查图层是否被设为 **锁定**。锁定图层可以选中，但不能拖动或变换。
- 检查图层是否取消了 **显示**，或者被其他不透明图层完全盖住。

### 图片放到字幕框外后不显示

- 先点击 **应用预览** 或 **保存**，让字幕窗口使用最新皮肤范围。
- 检查图层的水平、垂直锚定是否符合预期。
- 检查图片是否显示、透明度是否大于 0、缩放是否过小。
- 若字幕窗口刚被缩放，稍等编辑器完成尺寸同步后再检查位置。

### 贴图挡住字幕窗口工具栏

皮肤贴图可以出现在工具栏所在区域，但工具栏和按钮应始终处于最高 UI 层，并优先接收点击。如果按钮仍无法操作，请记录皮肤名称、贴图位置和复现步骤后反馈。

### 动画没有关键帧

- 确认左侧选择的是一个具体动作，而不是 **基础状态（无动作）**。
- 确认已经选中图层。
- 开启 **动作编辑时自动打点**，或修改后点击 **添加/更新**。
- 确认播放头位于你希望记录关键帧的时间。

### 事件测试有效，实际运行不触发

- 确认事件已勾选 **启用**。
- 检查触发冷却、动作冷却、触发概率和最多次数。
- 检查触发动作是否允许被当前正在播放的动作打断。
- `keyword` 和 `regex` 依赖实际收到的字幕文本；注意大小写选项。
- 音量事件使用 `0` 到 `1` 的阈值，需要根据实际声音逐步调试。

### 切换皮肤失败

- 使用顶部 **正在编辑：** 下拉框切换，确认当前修改已经保存或明确放弃。
- 若使用 **打开**，应选择有效的 `skin.json`。
- 空文件、损坏的 JSON 或素材引用丢失会导致加载失败；可恢复备份或重新导入皮肤包。

### 修改后下次打开恢复了旧状态

- 确认窗口标题中没有 `*`。
- 确认底部状态栏显示“已保存”。
- **应用预览** 只用于临时预览，必须点击 **保存** 才会持久化。

### 序列帧播放顺序不对

- 添加序列时按文件名顺序选择素材。
- 建议使用补零文件名，例如 `tail_001.png`、`tail_002.png`、`tail_003.png`。
- 保持每一帧的图片尺寸和主体位置一致。

## 11. 素材与性能建议

- 静态装饰优先使用单张 PNG/WebP，不要为了静态内容创建序列帧。
- 裁掉图片中过多的无用透明区域，但需要旋转的部件应保留足够空间。
- 多个可动部件应拆成独立图层，例如身体、耳朵、尾巴、眼睛。
- 先制作基础状态，再制作短小、可复用的独立动作。
- 序列帧数量和分辨率越高，占用的内存和渲染资源越多。
- 使用低频随机事件时设置合理冷却，避免多个动作频繁竞争。
- 完成后导出 ZIP 备份，便于迁移或恢复。
